# 白云机场收费收益权 ABS 建模

机场业务量预测、CIR 利率模拟、现金流与压力测试的课程研究。

## 运行

```bash
python -m pip install -r requirements.txt
python src/run_models.py
```

Python 3.10+。`data/` 是原课程工作簿中市场利率及机场业务量的 CSV 导出，`results/` 保存运行生成的预测和情景结果。原工作簿、个人署名论文和重复版本未上传。

## 整理时修正

GM(1,1) 用 2010—2019 数据训练，公开版按实际预测步长选取 2026—2029，修正原脚本将前五步预测直接贴上未来年份的问题。起降收费从“万元/架次 × 万架次”换算为亿元时系数为 0.65，修正原来的数量级错误。输出改为 CSV。

## 模型范围

费用、净现金流比例、发行规模和票息利差为课程假设。所谓 OAS 部分仅计算模拟利率下的现值差，未求解期权调整利差；压力测试中的利率冲击参数尚未进入偿债覆盖率计算。CIR 使用离散近似及截断。结果是课程情景研究，不代表实际发行条款或正式估值。
